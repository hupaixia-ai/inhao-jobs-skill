# INHAO 求职 Skill

把一份中文简历和两三个职位描述交给 Codex，它会逐项对照岗位要求和你的经历，给出匹配分、需要向招聘方确认的问题，以及可以直接放进简历的改写。适合应届生、社招和转岗求职者。

## 安装到 Codex

在 macOS 或 Linux 终端中运行以下命令，然后打开新的 Codex 对话。

```sh
mkdir -p ~/.agents/skills
git clone https://github.com/hupaixia-ai/inhao-jobs-skill.git ~/.agents/skills/inhao-jobs-skill
```

## 第一次使用

还在找方向时，可以附上脱敏简历，输入：

> 用 $inhao-jobs-skill 帮我判断在杭州可以搜哪些供应链岗位。我的税前月薪底线是 1.5 万元。请说明每个方向对应我哪段经历，并给我五组能直接在招聘平台使用的搜索条件。

手上已有岗位时，可以直接粘贴简历和职位描述：

> 用 $inhao-jobs-skill 对比下面三个职位。先检查我的硬条件，再按匹配度打分。挑出最值得投的一个，改写最多五条简历经历，并标出每条的原始依据。

## 每日职位推送

第一次拿到个性化搜索条件或岗位匹配结果时，Skill 会问你要不要每天接收新岗位。你同意后，它会沿用这次的求职条件，和你确认推送时间，并在支持定时通知的环境中设置任务。只在找到符合条件的新岗位时推送职位；你也可以随时要求调整条件或停订。

## 怎么判断一个岗位值不值得投

职责经验占 4 分，关键技能占 3 分，相关成果占 2 分，行业或业务场景占 1 分。达到 7 分、双方硬条件相容且申请入口可核实的岗位，才进入投递候选。比如岗位写着“接受夜班”，而你只能上白班，即使经验高度匹配，也会跳过。岗位没写班次时，会列为待确认。

查看在线职位需要当前对话能访问招聘页面。遇到登录限制，可以直接粘贴职位描述继续分析。完整流程见 [SKILL.md](SKILL.md)。
